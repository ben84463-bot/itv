## v0.7.0：Cloudflare 中繼站（建議）

觀測站、證交所、櫃買中心不允許網頁直接讀取。設定 `worker/worker.js` 為 Cloudflare Worker（免費，每天 10 萬次）後，網頁選股即自動抓取：財報附註關係人交易、重大訊息（含內文與交易對象）、法說會、背書保證與資金貸與、年報清單；統編改由證交所／櫃買中心／興櫃公司基本資料經中繼站取得。設定步驟見網頁「設定 → 設定步驟」。

## 檔案結構


## 部署（約 10 分鐘，一次就好）

1. GitHub 建立新的 **Public** repository（例如 `itv`）。公開 repo 的 GitHub Actions 免費、不計分鐘數。
2. 把整個資料夾內容上傳（解壓縮後全部拖進「Add file → Upload files」；注意 `.github` 資料夾也要上傳，若網頁上傳看不到隱藏資料夾，可在 repo 內「Add file → Create new file」，檔名輸入 `.github/workflows/crawl.yml` 再貼上內容）。
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。
4. Settings → Actions → General → Workflow permissions 選「Read and write permissions」→ Save（讓抓取程式能把資料存回 repo）。
5. Actions 分頁 → 「抓取關係人交易」→ Run workflow，代號欄輸入例如 `2313,2330` 試跑。完成後（每檔約 1～2 分鐘）打開 `https://帳號.github.io/itv/` 選該股票即可看到。
6. 之後排程每 3 小時自動跑一批：先抓 watchlist.txt，再逐步輪完全體上市櫃公司（第一次全部輪完約需數天，之後每季更新）。

### 同仁要查還沒抓過的股票
網頁會顯示「送出抓取請求」連結，開出的 GitHub Issue 標題為「抓取 2313」，送出後 Actions 自動執行並回覆，約 5～15 分鐘完成。需要 GitHub 帳號；公開 repo 任何人都能送出請求（每次最多 5 檔）。

### 用本機檔案開啟時
本機開啟無法讀取同資料夾的 data，請在「設定 → 關係人交易資料網址」填 `https://帳號.github.io/itv/data/`。

## 關係人交易擷取（v0.5.0 新增）

- 來源：公開資訊觀測站 `t164sb01` 財報頁（Inline XBRL，含附註），先抓合併報表，沒有才抓個體報表；每檔保留最近 4 季。
- 擷取內容：附註「關係人交易」段落的「關係人名稱及關係」（名稱、簡稱、關係）、各類交易表格（進銷貨、應收應付等）與原文；附表中的資金貸與、背書保證、與關係人進銷貨達一億元等表格。
- 只搬運原文，不推算；解析不到的會在網頁上標示原因，並附觀測站原始財報連結供核對。
- 選定股票後若卷宗內還沒有交易對手，會自動：帶入最新一季具名關係人（法人列為交易對手、自然人列為關係人）→ 商工核對 → 集團擴展 → 畫關係圖。也可按「帶入並自動核對、擴展集團、畫關係圖」手動重跑。

## 集團擴展規則

對每個已在商工查到的交易對手：

| 查詢 | 依據 | 歸類 |
|---|---|---|
| 以交易對手名稱查「所代表法人」 | 交易對手擔任法人董監事的公司（轉投資） | 登記事實 |
| 以交易對手的法人董監事名稱查「所代表法人」 | 由同一法人擔任董監事的兄弟公司 | 登記事實 |
| 以交易對手地址（到「號」）查地址 | 同門牌公司 | 登記事實；同址超過 40 家視為商務中心略過 |
| 以代表人／董事長姓名查（可在設定關閉） | 同名者擔任代表人或董監事的公司 | 待確認（同名不等於同一人）；同名超過 15 家略過 |

擴展出的公司再與標的公司比對：同門牌、同一法人董監事、同名董監事。有重疊者在關係圖標紅或黃，並列在留意清單最上方。

## 使用量與資料

- 網頁在每位同仁自己的瀏覽器執行，不經過你的伺服器、不用你的 Claude 額度或 Firebase 額度。
- 商工資料：g0v「台灣公司資料」API（https://company.g0v.ronny.tw/api），每人以自己的連線匿名查詢。
- 標案筆數：歐噴「政府採購公告」API（https://pcc-api.openfun.app/api），可在「設定」填入個人 Token；Token 只存在該同仁的瀏覽器。
- 紀錄存在瀏覽器 localStorage；換電腦、交接或清除瀏覽資料前，請先「匯出 JSON」。

## 判讀規則（程式內建）

| 比對結果 | 歸類 |
|---|---|
| 標的公司統編是交易對手的法人董監事（或反之） | 已確認事實（登記事實） |
| 雙方董監事由同一法人（同統編）代表 | 已確認事實 |
| 登記地址相同／同門牌不同樓層 | 已確認事實 |
| 交易對手非「核准設立」狀態 | 已確認事實 |
| 代表人、董監事、經理人同名 | 尚缺證據（同名不等於同一人） |
| 交易對手設立未滿約兩年 | 尚缺證據（需比對交易起始時間） |
| 商工查無 | 尚缺證據（可能為外國法人、名稱縮寫或自然人） |

## 股票搜尋與自動串接（v0.4.0 新增）

- 搜尋框可輸入代號、名稱或產業關鍵字（例：華通、2313、電子零組件），清單顯示代號、名稱、產業、上市／上櫃／興櫃。
- 點選後自動：① 由證交所／櫃買中心 OpenAPI「公司基本資料」取得統一編號與公司全名（查不到時改用台灣公司資料 API 名稱比對，並註明需核對）；② 載入商工登記；③ 抓歷年財報。
- 歷年財報來源 FinMind（原始資料為公開資訊觀測站）：近 6 年季報（損益、資產負債、現金流）、近 3 年月營收、股利。表格顯示營收、營收年增率、毛利／毛利率、營業利益／營益率、稅後淨利、EPS、單季營業現金流、現金、應收帳款、存貨、資產負債與負債比；另有「全部科目原始資料」。
- 自動財報觀察點（只提示，不下結論）：應收帳款或存貨年增率高於營收年增率逾 20 個百分點、毛利率較上季下滑逾 3 個百分點、近四季營業現金流不到淨利一半、近四季有兩季以上營業現金流為負。可一鍵加入「尚缺證據」。
- FinMind 免費額度：不帶 Token 每小時 300 次、註冊 Token 每小時 600 次，以各人連線計算；每選一檔股票約用 5 次。可在「設定」填個人 Token。
- 「設定 → 連線檢查」可逐一測試各資料來源能否從目前網路連線。
- 選另一檔股票時會自動開新卷宗，不覆蓋原本紀錄。

## 關係圖（v0.2.0 新增）

- 節點：標的公司（黑）、交易對手（依留意分數紅／黃／灰）、商工查無（灰虛線）、法人股東／法人董監事（菱形）、自然人（小圓）。
- 留意分數：登記事實重疊或非存續狀態各 3 分、同名 2 分、新設立等提示 1 分；3 分以上為高度留意（紅色外圈）。
- 淡黃框「疑似同集團」只依登記事實圈定：同地址、同一法人（同統編）擔任多家董監事、互為法人董監事；自然人同名不納入圈定。
- 預設只顯示出現在兩家以上公司的人與法人，可勾選「顯示全部董監事」；「只顯示留意路徑」會隱藏未見重疊的對象。
- 可拖曳、縮放、點選聚焦，滑鼠移到節點會顯示原始登記內容與附註出處；可下載 PNG／SVG，或列印存成 PDF（圖下會印出資料來源、輸出時間與「同名不等於同一人」）。
- 關係圖元件 d3 由 cdnjs.cloudflare.com 載入，內網若擋外部 CDN 會無法顯示。

## 已知限制

- 觀測站不開放網頁直接讀取，所以關係人交易改由 GitHub Actions 預先抓取；年報、重訊、法說會資料尚未自動化。
- 觀測站有流量限制，抓取程式每 4 秒一份、被擋自動暫停；觀測站改版或停用 mopsov 時，抓取程式需要更新。
- 解析器是依觀測站財報頁的公開範例格式撰寫，已用模擬頁面測試；各公司附註寫法不一，第一次正式執行後請抽查幾檔與原始財報比對。
- 商工資料為 g0v 彙整（經濟部每月異動清冊、財政部每日稅籍），不是經濟部官網即時狀態，正式文書以官方查詢為準。
- 匿名查詢可能遇到流量限制；同一機關共用對外 IP 時，同仁的查詢可能合併計算。
- FinMind、證交所、櫃買中心 OpenAPI 是否允許瀏覽器跨網域呼叫（CORS），建置環境無法實測，部署後請先跑「連線檢查」。
- 尚未在實際網路環境呼叫 API 測試（建置環境無法連線），比對邏輯已用模擬資料測試。
